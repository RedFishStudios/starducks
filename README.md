# Starducks

A Roblox experience.

## Setup
1. Install [Rokit](https://github.com/rojo-rbx/rokit), then run `rokit install` in this folder.
2. Install the Lync Studio plugin. `lync` places it in `%LOCALAPPDATA%/Roblox/Plugins` for you.
3. Run `lync serve`, open the place in Studio, and click **Connect** in the Lync plugin.

## Lint and format
```
stylua src
selene src
```
